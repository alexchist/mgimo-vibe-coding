# Орбита

Рабочий конкурсный концепт «Цифрового деканата будущего»: учёба, расписание, документы и следующий полезный шаг в одном кабинете.

**Неофициальный сервис.** Все студенты, преподаватели и учебные данные вымышлены. Университетские системы, логотипы и настоящие аккаунты не используются. Неделя 16–22 ноября 2026 года зафиксирована для воспроизводимой демонстрации; дата подписана в интерфейсе.

## Запуск

Нужен Node.js **24** (встроенный SQLite). Из корня репозитория:

```sh
npm ci
npm run dev
```

Vite слушает порт **5173**, API — **3001**. Для запуска собранного приложения:

```sh
npm run build
npm start
```

Собранный сайт и API работают на одном порту **3001**. База `data/orbita.sqlite` создаётся автоматически, включена в `.gitignore` и сохраняет заявки, уведомления, личный план и сессии. Не удаляйте её при перезапуске.

## Тестовые аккаунты

| Логин | Пароль | Данные |
| --- | --- | --- |
| `alisa@demo.orbita` | `Orbita2026!` | Первый вымышленный студент |
| `mark@demo.orbita` | `Orbita2026!` | Второй вымышленный студент с отдельными данными |

Это намеренно публичные демонстрационные аккаунты для жюри. Пользователи одного тестового аккаунта видят общие данные этого аккаунта. Не вводите настоящие персональные данные; пароли не подходят для других сервисов. В базе хранятся scrypt-хеши, не открытые пароли.

## Возможности

- Вход, выход и профиль; серверное разделение данных студентов.
- Расписание дня/недели, поиск, заметные переносы, экспорт календаря.
- Оценки, компоненты результата, сессия и калькулятор гипотетического результата.
- Создание заявки, история статусов, сохранение между перезапусками, скачивание маркированного демодокумента.
- Уведомления с отметками прочтения и переходами к действиям.
- Главная с ближайшими задачами; локальный навигатор по данным без внешнего ИИ/API.
- «Мой план»: свои задачи и учебные сроки, сохраняемые личные отметки, отмена выполнения и точные ссылки на дела. Отметка не означает сдачу работы преподавателю; учебные данные неизменны.
- Адаптивный интерфейс от 360 px и управление с клавиатуры.

Смена статуса заявки выполняется явной кнопкой демосимуляции. Никакие заявления в настоящий деканат не отправляются. Кабинет сотрудника не предусмотрен.

## Проверки

```sh
npm run build
npm test
npm run test:e2e
```

Браузерные тесты используют Chromium в `/usr/bin/chromium`; для другой установки задайте `CHROMIUM_PATH`. Например, установите Chromium средствами вашей ОС. API-тесты создают отдельные временные базы и проверяют вход, CSRF, чужие идентификаторы, заявки и сохранение после перезапуска. Браузерные тесты проверяют реальные сценарии, включая 360 px.

## Архитектура и безопасность

React + Vite, Express, SQLite. Сервер определяет владельца по сессии и добавляет его ID в каждый запрос к личным данным. Идентификаторы чужих объектов возвращают 404. Cookie HttpOnly / SameSite; изменения требуют CSRF-токен. Сессии ограничены по времени, в базе хранится хеш их случайного идентификатора. Пароли хешируются scrypt. Ввод проверяется сервером. В продакшене необходимы HTTPS, `COOKIE_SECURE=true`, корректный `APP_ORIGIN` и доверие только своему reverse proxy.

SQLite и один сервер подходят для демонстрации и небольшой нагрузки. Горизонтальное масштабирование потребует PostgreSQL, общего хранилища сессий/лимитов, миграций и отдельного фонового обработчика документов. Такая миграция здесь не заявляется как выполненная; внешние сервисы для прототипа не нужны.
