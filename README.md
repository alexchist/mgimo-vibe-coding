# Курсом — студенческий кабинет

**[Открыть кабинет](https://mykursom.ru)** · **[Отчёт для жюри (PDF)](docs/jury/Kursom-report-v4.pdf)** · **[Архитектура и четыре критерия](AGENTS.md)**

На входе нажмите **«Алиса»** или **«Марк»**. Это два общих учебных аккаунта с разным расписанием. Используйте только вымышленные данные.

Главная показывает, куда идти на пару и какое дело на очереди. Чтобы попробовать поиск по документам, откройте «Спросить GigaChat», задайте вопрос «Как оплатить общежитие?», затем уточните: «А до какого числа?». Названный срок можно сверить с пунктом положения прямо под ответом.

## Запуск

Нужен Node.js **24** (встроенный SQLite). Из корня репозитория:

```sh
npm ci
npm run dev
```

Vite слушает порт **5173**, API — **3001**. Для демо внешние ключи не нужны. При необходимости скопируйте `.env.example` в `.env` и заполните серверные настройки: `npm run dev` и `npm start` читают этот файл автоматически. Секреты не должны иметь префикс `VITE_` и попадать в Git. Для запуска собранного приложения:

```sh
npm run build
npm start
```

Собранный сайт и API работают на одном порту **3001**. База `data/orbita.sqlite` создаётся автоматически, включена в `.gitignore` и сохраняет заявки, уведомления, личный план, брони, демоплатежи, документы, подключения и сессии. Не удаляйте её при перезапуске. [Подробная настройка интеграций и MCP](docs/INTEGRATIONS.md).

## Тестовые аккаунты

| Логин               | Пароль        | Данные                                          |
| ------------------- | ------------- | ----------------------------------------------- |
| `alisa@demo.orbita` | `Orbita2026!` | Первый вымышленный студент                      |
| `mark@demo.orbita`  | `Orbita2026!` | Второй вымышленный студент с отдельными данными |

Это намеренно публичные демонстрационные аккаунты для жюри. Пользователи одного тестового аккаунта видят общие данные, загрузки и подключения этого аккаунта и могут отзывать его MCP-токены. Загружайте только учебные/вымышленные документы без настоящих персональных данных и секретов. Пароли не подходят для других сервисов. В базе хранятся scrypt-хеши, не открытые пароли. Настоящая привязка Telegram/VK по умолчанию выключена.

## Как проверить работу

На странице «Заявки и справки» выберите документ, посмотрите срок и оформите учебную заявку. Запомните номер, выйдите и снова войдите под тем же студентом: обращение останется в истории. Проверить другой кабинет можно под вторым аккаунтом.

## Проверки

```sh
npm run build
npm test
npm run test:e2e
```

Браузерные тесты используют Chromium в `/usr/bin/chromium`; для другой установки задайте `CHROMIUM_PATH`. Например, установите Chromium средствами вашей ОС. API-тесты создают отдельные временные базы и проверяют вход, CSRF, чужие идентификаторы, заявки и сохранение после перезапуска. Браузерные тесты проверяют реальные сценарии, включая 360 px.
