# Комплект для отправки

Капитан отправляет работу в конкурсном кабинете. Текст ниже нужно дополнить настоящим публичным адресом после развёртывания. Не отправляйте localhost или ссылку на репозиторий вместо ссылки на работающий прототип.

## Комментарий к работе

**Орбита — цифровой деканат будущего.** Неофициальный конкурсный концепт для студентов МГИМО, использует только вымышленные данные.

Прототип: **[вставить проверенный HTTPS-адрес после размещения]**.

Тестовые аккаунты:

- `alisa@demo.orbita` / `Orbita2026!`
- `mark@demo.orbita` / `Orbita2026!`

У аккаунтов разные профили, расписания, оценки и заявки. Регистрация не нужна. Кабинета сотрудника нет; кнопка «Демо: следующий этап» явно имитирует обработку заявки. Готовый документ — маркированный учебный образец.

Исходники: https://github.com/alexchist/mgimo-vibe-coding/tree/feat/orbita-student-portal

Описание создания: `docs/PROCESS.pdf` в репозитории. Текстовая версия, реальные промпты и исследование находятся рядом. Видеодемонстрация: `docs/DEMO.mp4`, 43 секунды. Для подачи загрузите видео на поддерживаемую конкурсом площадку и добавьте ссылку.

## Перед отправкой

- Развернуть приложение по `DEPLOYMENT.md`, обеспечить сохранность тома SQLite и HTTPS.
- Проверить адрес из России без VPN, в том числе на телефоне, и зафиксировать результат.
- Обеспечить работу до 28 ноября включительно.
- Убедиться, что жюри имеет доступ к репозиторию/архиву и PDF. Приватный репозиторий сам по себе не даёт доступа экспертам.
- Заменить placeholder публичной ссылки выше. Проверить оба тестовых аккаунта уже на размещённом экземпляре.
- Уточнить дедлайн подачи в конкурсном кабинете: в переданном задании 28 ноября обозначает дату итогов, а не явно указанный срок подачи.
