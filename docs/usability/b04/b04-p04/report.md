# b04-p04 — Марк, телефон 360 px

Синтетический независимый UX-проход. Прочитана только инструкция участника, далее использовался браузер. Задача выполнена, сессия завершена командой finish; приложение сообщило 10 actions, pageErrors и operatorErrors пустые.

## Фактический маршрут

- step 002: экран входа; выбрал видимую демокнопку Марка вместо ручного ввода выданных реквизитов (003).
- 004: перешёл в «Расписание» через нижнюю навигацию.
- 005: выбрал «Вс 22»; 006: прокрутил до результата «День без пар».
- 007: включил «Вся неделя», чтобы искать предмет по всей неделе, а не по пустому воскресенью.
- 008: ввёл «Японский язык» в поиск. Получил «По этим фильтрам занятий нет».
- 009: нажал «Сбросить фильтры». Вернулась вся неделя с пустым поиском.
- 010: прокрутил список и увидел английский в понедельник; затем finish.

## Ответ и результат

В воскресенье 22 ноября занятий нет: явно показан «День без пар». «Японский язык» поиском по полной демонстрационной неделе не найден. После сброса фильтров нашёл английский на понедельник 16 ноября, 10:35–11:55, преподаватель Даниил Леснев, аудитория 215Б в главном корпусе. Карточка поясняет перенос из 208 без изменения времени. Все части задачи выполнены; ручной вход по паролю не проверялся, остальные занятия английского в других днях визуально не просматривались.

## Что было понятно и что смутило

Пустое воскресенье и отсутствие результата поиска различаются заголовками, поэтому я понял причину пустоты. «Сбросить фильтры» позволило сразу вернуться к полной неделе. Немного смутило, что после выбора воскресенья кнопка «Сегодня в демо» продолжала выглядеть выбранной (006), хотя выбран день 22; маршрут это не заблокировало.

Предложение: в режиме отдельного выбранного дня убрать выделение «Сегодня в демо» либо назвать этот режим «Один день», чтобы состояние не спорило с выбранной датой (006).
