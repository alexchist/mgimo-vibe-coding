# b10-p01 — готовая справка с клавиатуры

Синтетическая независимая UX-проверка, Алиса, ширина 1440 px. Прочитана только инструкция участника; далее использовались видимый браузер и его снимки. После открытия раздела все действия выполнялись только `press` с единственным полем `key` (`Tab` и `Enter`).

**Результат: выполнено.** Скачана существующая справка об обучении ОРБ-0101, новая заявка не создавалась. На step 017 браузер зарегистрировал файл `orbita-demo-student-alisa-request-ready.html`. Содержимое файла не открывалось, использование во внешнем приложении не проверялось. Невыполненных частей поставленной задачи нет.

## Ясность пути и фокус

Путь понятен: «Мои заявки» → «Готовые 1» → карточка → «Скачать демодокумент»; короткий переход к списку позволил не проходить клавиатурой форму новой заявки. Фокус хорошо виден на кнопке перехода, заголовке списка, фильтре, карточке и скачивании (007, 008, 011, 014, 016). Непонятных названий или тупиков не возникло; готовая карточка первоначально ниже экрана, но фильтр сразу вывел её в видимую область (006 → 012).
