# b06-p04 — две подготовки справок

Синтетический независимый участник, экран 1440 px, Алиса. Прочитана только инструкция участника; работа выполнена через браузер, без исходников, API и чужих отзывов.

Задача выполнена: две отдельные подготовки получены, подготовка для конкурса Вега отменена, справка для стажировки Лира оформлена. После обновления сохранена демо-заявка **ОРБ-A2C838BE**, тип «Справка об обучении», назначение «стажировки Лира», статус «Принята». В списке четыре заявки: новая и три более ранние; новой заявки для Веги нет. В настоящий деканат ничего не отправлено.

Фактический маршрут:

- 002–005: осмотр входа, ввод предоставленных учётных данных, вход.
- 006: переход по ссылке «Навигатор».
- 007–008: вопрос «Подготовь справку об обучении для конкурса Вега. Пока не подавай заявку.» Получена карточка с целью «конкурса Вега», без оформления.
- 009–010: вопрос «Отдельно подготовь справку об обучении для стажировки Лира. Пока не подавай заявку.» Вместо подготовки получена общая инструкция и кнопка «Посмотреть готовый документ».
- 011–012: повторил тот же запрос без начального «Отдельно». Появилась вторая карточка с целью «стажировки Лира»; первая сохранилась.
- 013: прокрутка, осмотр второй карточки.
- 014: нажал первую из двух одноимённых кнопок «Отменить подготовку» (nth:0, по порядку карточек в дереве). У Веги появился заголовок «Подготовка отменена» и сообщение о сохранении остальных подготовок. Кнопка подтверждения Лиры осталась доступна.
- 015: подтвердил оставшееся действие. У Лиры появился статус «Действие выполнено» и сообщение о создании демо-заявки.
- 016–017: перешёл в «Заявки и справки», обновил страницу. Проверил номер, тип, назначение и статус новой заявки.
- finish: сессия завершена; инструмент сообщил actions:17, pageErrors:[], operatorErrors:[], downloads:[].

Непонятное: почему слово «Отдельно» перед понятным запросом изменило результат на общую инструкцию; интерфейс не объяснил, что подготовка не создана. Для действий двух карточек используются одинаковые названия кнопок, поэтому в браузерном пульте потребовался выбор по порядку; сам по себе этот способ выбора не доказывает дефект UI.

Предложение: обрабатывать запрос с вводным «Отдельно» так же, как без него, либо явно сообщать, что действие не подготовлено; доказательство — разные ответы в шагах 010 и 012 при удалении только этого слова.

Ошибки инструмента/участника: ошибок команд не было. Вывод некоторых промежуточных fill/scroll был сокращён лимитом вывода; результаты отправки вопросов и финальной проверки прочитаны полностью. Не проверялись внутреннее состояние базы, архив и действия за пределами интерфейса; обязательных невыполненных частей нет.
