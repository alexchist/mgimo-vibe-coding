# b03-p02 · desktop

## Итог

Заметку удалось создать через вставку текста без файла, найти по словам «три вопроса» и открыть её источник. После удаления заметка пропала из списка, но повторный поиск тех же слов выдал два общих документа из-за совпадений по отдельным словам; точное условие «заметка больше не находится» не выполнено однозначно.

## Маршрут

- **002** — посмотрел экран входа; выбрал видимую демокарточку Марка.
- **003** — кабинет Марка; перешёл в «Кампус», затем в «Базу знаний».
- **005–008** — ввёл название «Памятка клуба «Меридиан»» и заданный текст в поле «Или вставьте текст», нажал «Добавить в базу». Появилось подтверждение «Документ добавлен. Теперь его текст доступен в поиске», документ стал выбран и показал полный фрагмент.
- **009–010** — поиск по фразе «три вопроса» вернул один результат: нужную памятку с полным фрагментом.
- **011** — нажал «Открыть источник Памятка клуба «Меридиан», Фрагмент 1»; область источника с заголовком и полным текстом была видна.
- **012–013** — нажал удаление, затем подтвердил «Да, удалить документ». Система сообщила, что документ и его фрагменты удалены; в списке осталось пять документов.
- **014** — повторил поиск. Памятки уже нет, но появились два общих результата: «Порядок выдачи справок и подачи заявлений» и «Положение о стипендии».

## Выполнение и наблюдения

- Добавление без файла: выполнено.
- Найти фразу и открыть источник: выполнено.
- Удалить памятку: выполнено.
- Проверить отсутствие результата: памятка исчезла, однако поиск по той же фразе вернул два документа с совпадениями по отдельным словам «три» / «вопроса»; общий поиск не стал пустым.
- Что было непонятно: после удаления неясно, подразумевает ли интерфейс под «не находится» отсутствие именно удалённой заметки или отсутствие любых результатов. Названия и фрагменты источников помогают различать совпадения.
- Ошибки инструмента/участника: нет.
