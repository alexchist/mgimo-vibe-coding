# Исправление нестабильной проверки контраста, 17 ноября 2026

Запрос: после диагностики упавшего CI пользователь разрешил исправить проблему и отправить изменения в рабочую ветку `feat/orbita-student-portal`.

## Причина

[Запуск 44052945850](https://github.com/alexchist/mgimo-vibe-coding/actions/runs/44052945850) на `603ec41`: сборка и 106 серверных тестов прошли; из 52 браузерных тестов упал один сценарий архивирования и открытия документа из уведомления на мобильном экране.

После перехода тест проверял видимость ссылки и сразу запускал axe, пока `.svc-page` ещё появлялась с анимацией прозрачности длительностью 250 мс. На отметке 200 мс прозрачность составляет 0.975625: мобильный цвет `#637467` смешивается с фоном `#f5f6f8` в `#67776b`, давая ровно зарегистрированные CI 4.38:1 вместо требуемых 4.5:1. Более специфичный мобильный `.page-heading p` перекрывал общий `.muted`.

Диагностика выполнена через GitHub Actions logs/artifact (trace и screenshot), чтение CSS и изолированное приложение с SQLite `:memory:`. В браузере на неизменённом исходнике воспроизведены нарушения во время анимации; после её завершения axe не нашёл нарушений. Диагностическая остановка анимации на 200 мс воспроизвела точные цвет и контраст из CI.

## Изменения

- Перед axe в сценарии архивирования ожидается завершение конечных анимаций, как уже сделано в остальных accessibility-тестах. Бесконечные анимации исключены; отмена анимации обработана. Фиксированных задержек, исключений правил и снижения порога контраста нет.
- Мобильный цвет `.page-heading p` заменён на общий `#526272`: контраст конечного состояния на `#f5f6f8` повышен примерно с 4.60 до 5.80:1. Анимация интерфейса сохранена.
- Независимый агент `ci_config_audit` проверил diff без изменений файлов; замечаний не нашёл.

## Проверки

Локальный прогон выполнен с Chromium 159.0.8154.6 (Playwright build 1255), соответствующим упавшему CI, и Node 24.22.1:

- `npm ci --cache /tmp/mgimo-npm-cache` — успешно. Стандартный npm cache в домашнем каталоге недоступен в этой среде; временный каталог решил проблему без изменения проекта.
- `npm run build` — успешно.
- `npm test` — 106/106.
- `npm run test:e2e` — 52/52, включая мобильные и desktop проверки доступности. `CHROMIUM_PATH` указывал на загруженный Playwright Chromium, а не системный браузер.
- `npm run test:e2e -- tests/e2e/audit.spec.js --grep 'archiving keeps the document' --repeat-each=5 --output=/tmp/mgimo-ci-fix-repeat` — 5/5 дополнительных повторов на том же Chromium.
- Изолированный браузер, экран 360×800: фактический цвет подзаголовка `rgb(82, 98, 114)`, итоговая прозрачность 1, ширина страницы 360 px. [Скриншот](ci-contrast-fix-mobile.png) просмотрен: текст читается, переносы и расположение элементов сохранены.
