# Батч 2 — повтор и новые сценарии

Исходная версия: `beda2c6`. Все пять независимых участников завершили браузерные сессии. Оркестратор прочитал первичные отчёты, шаги и события пяти trace.zip; ошибки пульта проверены отдельно. До старта был исправлен [сбой инфраструктуры](INFRASTRUCTURE.md), который не считается ошибкой сайта.

| Находка / результат | Проверка и решение |
| --- | --- |
| p01 снова нашёл перенос, но прочёл детали ниже экрана через дерево доступности | Повтор подтвердил потерю визуального контекста. Ссылка с главной теперь сохраняет ID пары, открывает правильный день, прокручивает к карточке и переводит фокус. «Показать» изменения делает то же. До исправления независимый браузерный тест воспроизвёл отсутствие фокуса; после проверены полный вид карточки на телефоне и reload точной ссылки |
| p02 получил именно новую справку и повторно скачал её из архива | Полный маршрут теперь проверен, прежнее замечание о раскрытии не повторилось. Это не сравнение скорости моделей: формулировка задания стала точнее |
| p02 заметил дату создания 17-го и срок 19-го при трёх рабочих днях | Московская дата создания корректна: trace 16 ноября 21:30 UTC соответствует 17 ноября 00:30 МСК. Однако расчёт срока действительно ошибочен — использовал UTC-день. Исправлен календарный отсчёт по Москве; ожидаемая дата новой заявки — 20 ноября. Старые записи, UTC-метки и результаты повторных запросов сохраняются; праздники не моделируются |
| p03 оплатил ноябрьское демоначисление 4 200 ₽, скачал образец и проверил reload | Подтверждено журналом и трейcом, новых препятствий не выявлено. Скачивание не выдаётся за просмотр файла или настоящее списание |

Вопрос о стипендии без запроса документа теперь получает проверяемые источники. Явный заказ справки и отдельное подтверждение остаются прежними |
| p05 выполнил весь план, но добавление задачи переключило «Все» на «В работе» | Ненужное изменение контекста устранено: «Все» сохраняется. Из фильтра готовых новая невыполненная задача по-прежнему открывается в работе |
| p05 предложил пустую дату по умолчанию и российский формат нативного поля | Пожелание о дополнительном клике сохранено; согласованный предел демонедели не менялся. Вид нативного date/file-поля зависит от браузера/ОС; его английский формат не считаем доказательством неправильной сохранённой даты |

Ошибки пульта: p02 искал label без звёздочки обязательного поля, затем корректно использовал доступное имя textbox. p05 столкнулся с post-click проверкой `setChecked`, когда React уже изменил/удалил карточку; по состоянию и reload действия состоялись. Пульт теперь один раз кликает при отличающемся состоянии и показывает результат, не делая ложной повторной попытки. В итогах пульта разделены `pageErrors` и `operatorErrors`.
