# Как подключить уведомления «Курсом» к VK

Бот работает от имени **сообщества VK**. Студент связывает личный диалог с учётной записью на сайте и получает в VK новые уведомления. Для настройки понадобятся права администратора сообщества, доступ к серверному `.env` и опубликованный сайт с работающим HTTPS. Если сайт пока запускается только на вашем компьютере, сначала разместите его на домене. [Развёртывание с Docker Compose](DEPLOYMENT.md)

**Для первой проверки используйте отдельное тестовое сообщество и экземпляр сайта с ограниченным доступом к студенческому интерфейсу.** У опубликованных демологинов общие заявки и подключения для всех, кто входит под одним логином. Участники такой учётки могут отправлять тесты и менять привязку. При ограничении доступа оставьте для VK открытым HTTPS-маршрут `POST /api/channels/vk/webhook`.

## 1. Создайте сообщество и ключ сообщений

1. В веб-версии VK откройте **Сообщества → Создать сообщество**. Задайте имя, например «Курсом — тест», и откройте созданное сообщество. Можно использовать уже существующее, которым вы управляете.
2. В сообществе откройте **Управление → Сообщения**, включите **Сообщения сообщества** и сохраните. Посетителю должна быть доступна кнопка для личного сообщения сообществу.
3. Откройте **Управление → Работа с API → Ключи доступа → Создать ключ**. Предоставьте разрешение **«Сообщения сообщества»**. VK может обозначить его как доступ к сообщениям сообщества. Подтвердите выдачу и сохраните значение в `VK_GROUP_TOKEN` на сервере. [Право MESSAGES в SDK VK](https://github.com/VKCOM/vk-php-sdk/blob/master/src/VK/OAuth/Group/Scopes.php)
4. Запишите **числовой ID сообщества** в `VK_GROUP_ID`. Например, у `vk.com/club123456789` это `123456789`. Если используется короткое имя, возьмите `group_id` из примера запроса `confirmation` в настройках Callback API на следующем шаге. В `.env` нужны только цифры, без минуса и префикса `club`.

## 2. Подготовьте Callback API в VK

1. Откройте **Управление → Работа с API → Callback API → Настройки сервера**. Добавьте сервер либо выберите новый слот для этого проекта. Если VK предлагает несколько серверов, сохраните остальные подключения сообщества. Назовите новый сервер, например, `Курсом`. Названия вкладок могут отличаться между версиями интерфейса.
2. В поле адреса введите `https://ВАШ-ДОМЕН/api/channels/vk/webhook`. При выборе версии укажите **5.199**. Это версия официальной схемы, с которой работает проект. [Версия схемы VK](https://github.com/VKCOM/vk-api-schema#readme)
3. Сгенерируйте **секретный ключ** командой `openssl rand -hex 24`. Полученные 48 символов введите в поле **«Секретный ключ»** сервера в VK и в `VK_WEBHOOK_SECRET` на сервере приложения. Callback API передаёт этот секрет в JSON. [Параметр `secret_key` в официальной схеме](https://github.com/VKCOM/vk-api-schema/blob/master/groups/methods.json)
4. На той же странице VK показывает **строку, которую должен вернуть сервер** при подтверждении адреса. Скопируйте её в `VK_CONFIRMATION_TOKEN`. Оставьте вкладку открытой до перезапуска сайта.

## 3. Заполните `.env` на сервере и примените настройки

Если сайт уже размещён, в каталоге проекта на сервере обновите ветку `feat/orbita-student-portal` командой `git pull --ff-only origin feat/orbita-student-portal`, находясь на этой ветке. При первой установке возьмите эту ветку по [инструкции развёртывания](DEPLOYMENT.md).

Откройте `.env` в каталоге проекта и обновите следующие строки. В примере все значения в угловых скобках нужно заменить. Сохраните остальные настройки и ограничьте доступ к файлу командой `chmod 600 .env`.

```dotenv
DOMAIN=<домен сайта без https:// и пути>
VK_GROUP_ID=<числовой ID сообщества>
VK_GROUP_TOKEN=<ключ доступа сообщества с правом на сообщения>
VK_WEBHOOK_SECRET=<тот же секретный ключ, что в настройках Callback API>
VK_CONFIRMATION_TOKEN=<строка для подтверждения, которую показывает VK>
VK_API_VERSION=5.199
ALLOW_REAL_CHANNEL_LINKING=true
```

`DOMAIN` используется при запуске через Compose. Настройки `VK_*` предназначены для серверного процесса. Не помещайте их в `VITE_*`, Git, скриншоты или чат. Для получения уведомлений нужен исходящий доступ с сервера к `api.vk.com` по HTTPS.

Для Docker Compose выполните в каталоге проекта следующие команды. `up` пересоздаст контейнер с новыми переменными. `config --quiet` проверяет конфигурацию без вывода значений ключей.

```sh
docker compose config --quiet
docker compose up -d --build
docker compose ps
```

Если запускаете Node напрямую, выполните `npm run build` при обновлении кода и перезапустите серверный процесс командой `npm start` из каталога проекта либо через используемый менеджер процессов. `npm start` читает `.env` при старте. В браузере проверьте `https://ВАШ-ДОМЕН/api/health`.

## 4. Подтвердите адрес и подпишитесь на события

1. Вернитесь к настройкам сервера в VK и нажмите **«Подтвердить»**. VK отправит на указанный адрес запрос `confirmation`. Сайт сверит ID сообщества и секретный ключ, затем вернёт строку подтверждения простым текстом. Дождитесь отметки VK о подтверждении адреса. [Пример проверки и ответов в SDK VK](https://github.com/VKCOM/vk-php-sdk#62-callback-api)
2. Выберите этот сервер во вкладке **«Типы событий»**. В разделе сообщений включите **входящие сообщения** (`message_new`) и **запрет сообщений** (`message_deny`). Сохраните. Первое событие передаёт личное сообщение с кодом, второе сообщает сайту, что пользователь запретил сообщения от сообщества. [Типы событий VK](https://github.com/VKCOM/vk-api-schema/blob/master/groups/methods.json)

## 5. Привяжите диалог и получите первое сообщение

1. Войдите в тестовую учётную запись на сайте. Откройте **Подключения → VK → Подключить VK**. Эту же кнопку можно нажать при активном демоподключении. После подтверждения сервер заменит его на личный диалог.
2. Нажмите **«Скопировать код»**, затем **«Открыть диалог VK»**. Со своей страницы VK отправьте код сообществу **целиком отдельным личным сообщением**. Если VK предлагает разрешить сообщения от сообщества, подтвердите. Код действует 10 минут и связан с текущей сессией сайта. Выйдя из аккаунта, придётся создать новый код.
3. Вернитесь на сайт. Должна появиться надпись **«Личный диалог подключён»**. Чтобы проверить привязку вручную, нажмите **«Проверить подключение VK»**.
4. В карточке VK нажмите **«Отправить тест в VK»**. Убедитесь, что уведомление появилось **в диалоге VK**. На сайте нажмите **«Обновить статус»** и откройте журнал. Статус **«Принято провайдером»** означает, что VK принял отправку. Затем можно создать учебную заявку, изменить её демостатус и проверить новое уведомление в том же диалоге. [Метод `messages.send`](https://github.com/VKCOM/vk-api-schema/blob/master/messages/methods.json)
5. Для отключения выберите **«Отключить VK»** на сайте и подтвердите. Также можно запретить сообщения в настройках диалога VK. При включённом `message_deny` VK передаст отзыв разрешения сайту. Для новой привязки разрешите сообщения и получите новый одноразовый код.

## Если подключение остановилось

| Что видно | Что проверить |
| --- | --- |
| VK не подтверждает адрес | Домен доступен VK извне по HTTPS, сертификат действителен. Адрес заканчивается на `/api/channels/vk/webhook`. Прокси пропускает POST с JSON без редиректа и без страницы входа. Для 403 сверьте `group_id` и секрет, для неверной строки ответа сверьте `VK_CONFIRMATION_TOKEN` с настройками того же сообщества. После правок `.env` примените настройки заново. |
| В карточке VK доступно только демо | Проверьте `ALLOW_REAL_CHANNEL_LINKING=true`, числовой ID, все три значения из VK/Callback API и фактическое пересоздание контейнера. При отсутствии конфигурации доступен локальный журнал. |
| Сервер в VK подтверждён, а диалог не подключается | Проверьте подписку именно этого сервера на `message_new`, затем код, срок и отправку из личного диалога с нужным сообществом. Создание нового кода заменяет предыдущий. Если этот диалог уже привязан к другой учётке, отключите прежнюю привязку. |
| Привязка есть, но уведомления не приходят | Проверьте новый тест в карточке VK, разрешение на сообщения в диалоге, право ключа сообщества **«Сообщения»**, доступ сервера к `api.vk.com` и журнал доставки на сайте. Статус неизвестного результата допускает, что сообщение уже пришло. Сначала проверьте диалог. |

При необходимости проверьте, какие переменные переданы **запущенному** контейнеру. Команда выводит только `задано` или `пусто` для каждого имени и значение переключателя.

```sh
docker compose exec -T app node -e 'for (const name of ["VK_GROUP_ID","VK_GROUP_TOKEN","VK_WEBHOOK_SECRET","VK_CONFIRMATION_TOKEN","VK_API_VERSION"]) console.log(name, process.env[name] ? "задано" : "пусто"); console.log("Привязка разрешена", process.env.ALLOW_REAL_CHANNEL_LINKING === "true")'
```
